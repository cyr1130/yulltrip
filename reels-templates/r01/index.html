릴스01 템플릿

모션을 고르면 이미지·문구·길이·색을 바꿔서 MP4로 내보낼 수 있는 편집 페이지가 열려요.

01 모션
버튼 → 원형 리빌
+ 버튼이 돌고 빛나는 원이 퍼지며 노드 캔버스가 열려요 · 약 2초
03 모션
노드 → 풀스크린 → 설정
결과가 화면 가득, 모델 목록·카메라 설정 후 최종 영상 · 약 9.6초
06 모션
AI 패널 → 댓글 → 로고 엔딩
채팅 입력 → 댓글 게시·게시자 답글·하트 → 단색 로고 엔딩 · 약 11.8초
07 모션
AI 패널 → 댓글 카드 → 로고 엔딩
06과 같고, 댓글창이 좌우 여백 있는 둥근 카드로 떠올라요 · 약 6.3초
08 모션
댓글 카드 + 하트
채팅창·로고 엔딩 없이 댓글 카드만 · 하트가 길게 떠올라요 · 약 8.1초
09 모션
모델 배지 + 키워드 + 별
배지 사이로 키워드가 나오고 별로 모여요 · 약 2.7초
10 모션
기능 카드
흰 화면에서 기능 카드가 한 장씩 넘어가요 · 약 3.4초
11 모션
카드 등장
이미지 1~3장이 종이처럼 날아 들어와요 · 약 2.5초
12 모션
노드 그래프 → 줌아웃 타이틀
프롬프트 입력·노드 그래프 → 줌아웃되며 큰 타이틀 · 약 3.8초
사용 팁 · 편집 내용(넣은 이미지 포함)은 저장되지 않아요. 새로고침하면 기본값으로 돌아가니, 다 만들면 바로 MP4로 내보내세요. 내보내기는 Chrome 에서만 되고 인터넷 연결이 필요해요.
