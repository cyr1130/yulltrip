릴스03 템플릿

모션을 고르면 이미지·문구·길이·색을 바꿔서 MP4로 내보낼 수 있는 편집 페이지가 열려요.

01 모션
피드 카드 전환
스토리 → 게시물 → 릴스 카드가 톡톡 바뀌고 숫자가 올라가요 · 약 2.9초
02 모션
로고 + 프롬프트 입력
두 브랜드 이름 등장, 문장 타이핑 중 제품 사진 첨부 · 약 4.1초
03 모션
Analyzing → Analyzed
사진 가장자리 빛 + 흐림, 분석 중 알약이 결과 카드로 커져요 · 약 4.3초
04 모션
콘텐츠 캘린더 줌 → Post
캘린더에서 날짜 칸으로 확대, 카드 탭하면 Post 버튼 · 약 2.9초
사용 팁 · 입력한 글자·색·사진은 이 브라우저에 자동 저장돼서 다시 열어도 그대로예요 (편집 페이지의 '기본값으로 되돌리기'로 초기화). 모든 모션에 배경 방식(단색 / 크로마키 초록)이 있고, 투명 배경 WebM 내보내기도 돼요. 내보내기는 Chrome 에서만 되고 인터넷 연결이 필요해요.
